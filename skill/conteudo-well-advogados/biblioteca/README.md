# Biblioteca de conteúdo publicado

Cada post publicado vira uma ficha `.md` em `publicados/` (e, se for carrossel, a capa em PNG com o mesmo nome). A skill consulta antes de sugerir pauta, para não repetir tema e para partir do que funcionou.

## Ficha (modelo)

```
# <AAAA-MM-DD>_<tema-curto>
- Formato: vídeo ou carrossel
- Pilar:
- Gancho usado:
- Alcance:
- Salvamentos:
- Compartilhamentos:
- Comentários:
- Seguidores ganhos:
- Por que funcionou / por que não funcionou:
- Comentários que viraram pauta:
```

Bom resultado aqui é salvamento, compartilhamento e comentário de advogado, não só curtida.
